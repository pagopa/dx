Require AzureRM v5 and drop v4 support in this module and its examples/tests.

Use the published dual-compatible Role Assignments 5.x dependency instead of the v4-only 4.x release; its inputs and resource addresses are unchanged.

Examples reference the planned v5-only App Configuration major so they include the compatible runtime dependency. Registry initialization must wait for that major to be published and indexed; development checks use temporary local module sources.

## Migration guide

Upgrade the root `hashicorp/azurerm` requirement to `~> 5.0` and select v5-compatible versions of every module and transitive dependency before adopting this major. Retain Terraform `>= 1.16.0`, or any higher minimum already required by your configuration. Run `terraform init -upgrade`, commit the updated `.terraform.lock.hcl`, and review `terraform plan` and the AzureRM v5 upgrade guide before applying. No production resource addresses are renamed by this change.

These v5-only majors are planned for a future release. Older dual-compatible module versions remain usable during the published AzureRM v4 support window ending 31 December 2026. This change does not migrate modules that still require v4.
