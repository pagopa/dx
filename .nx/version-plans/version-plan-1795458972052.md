The preset ships flattened TypeScript config entries

`@pagopa/oxlint-config/base` and `@pagopa/oxlint-config/base-jest` export the variants as configuration objects that `oxlint.config.ts` can import directly, with `core.json` already inlined: oxlint's TypeScript config accepts objects in `extends`, never paths. The JSON entries, their contents and their semantics are unchanged.
