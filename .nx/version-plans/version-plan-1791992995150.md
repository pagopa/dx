Support tenant-qualified GitHub environment names with the opt-in
`github_environment_prefix_enabled` flag (default `false`; existing lifecycle
names and deployments are unchanged unless it is enabled).

For existing repositories opting in, stage the tenant-qualified GitHub
environments, protections, and credentials before switching workflows. Azure
federated credentials require unique issuer/subject pairs: adopt or import them
at the existing Terraform resource addresses rather than creating duplicates.
Keep legacy credentials and environments until the new workflows are verified,
then retire them.
