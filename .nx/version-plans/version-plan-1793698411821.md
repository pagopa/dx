Support AzureRM v5 in Core Infra

## Migration guide

1. Update the Core Infra module constraint to `~> 8.0`, the AzureRM provider constraint to `~> 5.0`, and use Terraform `>= 1.16.0`.
2. Run `terraform init -upgrade` in the consuming root module.
3. Review the complete plan before applying. AzureRM v5 changes the private DNS virtual-network link configuration to use `private_dns_zone_id`; the resource addresses are unchanged, so no `terraform state mv` is required. The VNet, subnets, and private DNS zones must not be replaced. If the plan proposes replacing any of them—or replacing a DNS link—stop and investigate before applying.
4. No Core Infra input or output changes are required.
