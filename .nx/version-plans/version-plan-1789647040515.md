Federate Azure managed identities with GitHub repositories that emit immutable OIDC subject claims (created or renamed after 2026-07-15). The DX CLI and the Azure Terraform modules now create an additional federated identity credential embedding the numeric GitHub owner and repository IDs, keeping the name-based credential for older repositories.
