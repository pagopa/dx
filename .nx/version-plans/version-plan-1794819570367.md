Accept partial Azure Monitor options in `initAzureMonitor`, merged over the environment-derived defaults instead of replacing them.

**Behavior change**: the second argument of `initAzureMonitor` is now a **partial override**, not a complete configuration. The environment is parsed and validated on every call, so an invalid environment variable throws even when a complete configuration is passed, and the environment-derived defaults (live metrics, sampling ratio, `tracesPerSecond`, the Entra ID credential) are always applied. Overriding a single group (for example only `azureMonitorExporterOptions.connectionString`) therefore also keeps the environment `samplingRatio`, instead of falling back to the Azure Monitor SDK default. Properties explicitly set to `undefined` are ignored and do not shadow the environment values. `APPLICATIONINSIGHTS_ENTRA_ID_AUTH_ENABLED` is now matched case-insensitively and any value other than `true` disables Entra ID authentication instead of failing validation. `AzureMonitorOptionsOverride` is now exported from `@pagopa/azure-tracing/azure-monitor`.
