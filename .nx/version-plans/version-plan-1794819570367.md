Accept partial Azure Monitor options in `initAzureMonitor`, merged over the environment-derived defaults instead of replacing them.

**Behavior change**: the second argument of `initAzureMonitor` no longer replaces the whole configuration. The environment is now parsed and validated on every call, so an invalid environment variable throws even when a complete configuration is passed, and the environment-derived defaults (live metrics, sampling ratio, `tracesPerSecond`, the Entra ID credential) are always applied. Properties explicitly set to `undefined` are ignored and do not shadow the environment values. `AzureMonitorOptionsOverride` is now exported from `@pagopa/azure-tracing/azure-monitor`.
