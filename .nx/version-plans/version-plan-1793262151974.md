Move Terraform plugin publishing configuration to project.json metadata

## Migration guide

Terraform module publishing metadata is no longer read from `module.json`.
Move `description`, `provider`, `version`, and optional `github.owner` into the
`metadata` object of the module's existing `project.json`:

```json
{
  "name": "my-terraform-module",
  "metadata": {
    "description": "Terraform module description",
    "provider": "azurerm",
    "version": "1.2.3",
    "github": {
      "owner": "my-github-owner"
    }
  }
}
```

The plugin no longer configures Nx Release versioning for Terraform modules.
Manage module version bumps outside `nx release`; the publish target reads
`metadata.version` from `project.json`.
