Make `dx init` bootstrap the mise toolchain without manual steps.

`setupPnpm` now trusts the freshly generated mise config before running `mise
lock` (which, unlike `mise install`/`mise exec`, refuses untrusted configs) and
pins pnpm through Corepack before locking, so mise resolves it from the idiomatic
version file and records it in `mise.lock`. The generated `mise.toml` mirrors the
DX settings: `pnpm` and `python` join `node` and `terraform` in
`idiomatic_version_file_enable_tools`, and `minimum_release_age_excludes` covers
`copilot` and `github-cli`.
