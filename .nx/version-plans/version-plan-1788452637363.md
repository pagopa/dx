Authenticate Terraform module downloads with the automatic workflow
`GITHUB_TOKEN`: GitHub treats the repository token as authenticated traffic
even when cloning public repositories owned by other organizations, avoiding
the anonymous anti-abuse 401 during `terraform init`.

Newly generated bootstrapper workflows wrap Terraform initialization in the
`.github/actions/run-with-github-auth` composite action, which provides a
step-scoped Git credential helper without requiring any extra secret.
