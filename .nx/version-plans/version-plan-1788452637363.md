Expose the GitHub App token as an explicit output instead of exporting it to
every subsequent job step.

## Migration guide

Read the token from the `github_app_token` output and pass it only to steps that
require GitHub App access:

```yaml
- name: Cloud Login
  id: cloud-login
  uses: pagopa/dx/actions/csp-login@main

- name: Run GitHub command
  env:
    GITHUB_TOKEN: ${{ steps.cloud-login.outputs.github_app_token }}
  run: gh api user
```

Terraform initialization authenticates GitHub module downloads with the
automatic workflow `GITHUB_TOKEN`, which GitHub treats as authenticated traffic
even when cloning public repositories owned by other organizations. No extra
secret is required; the new
`.github/actions/run-with-github-auth` composite action configures a
step-scoped Git credential helper and proactive authentication.

Newly generated bootstrapper workflows wrap Terraform initialization in the
same authenticated action.
