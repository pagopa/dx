Reject unsupported repository HCL before modifying it; preserve unrelated Terraform configuration.

## Migration guide

Custom `infra/repository/main.tf` files that relied on a top-level
`repository = { ... }` attribute or a computed `environments` expression are
no longer updated by `dx add environment`. Move the repository object into
the generated `module "github_repository"` and express `environments` as a
list of unique literal names, for example `["dev", "prod"]`. You can omit the
list when only the implicit `prod` environment is needed. The CLI now reports
unsupported layouts before writing the file.
