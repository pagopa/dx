Migrate repository pnpm tooling to Aqua without changing pnpm 11.23.0 or release-age policies. Breaking contributor-environment change: native macOS x64 (Intel Macs and Rosetta x64 shells) no longer has a supported locked pnpm binary. Use the repository Linux development container on Intel Macs, or a native ARM64 shell on Apple Silicon. On supported platforms, run mise install --locked --force pnpm after updating the checkout. Keep mise.toml and package.json pnpm versions aligned.
