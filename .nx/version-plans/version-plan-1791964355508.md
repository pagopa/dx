Align the dx init scaffold with the validate-v2 pipeline.

The generated repository now configures @pagopa/nx-terraform and @pagopa/nx-docker, ships the Code Review workflow calling validate-v2.yaml, formats with oxfmt, includes the Trivy configuration, and authenticates to GitHub Packages. dx add environment registers tenant-qualified environments in nx.json, and dx doctor validates the Nx Terraform plugin instead of the legacy pre-commit configuration. validate-v2 now skips the version-plan warning when the release App secrets are not configured, so generated repositories pass the Code Review without manual setup. Both dx init and dx add environment run the Nx Terraform init target at the end of the generation, scoped to the projects they generated or updated, so the provider and module lock files are committed with them and pass the frozen-lockfile validation.
