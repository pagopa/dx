Align the dx init scaffold with the validate-v2 pipeline.

The generated repository now configures @pagopa/nx-terraform and @pagopa/nx-docker, ships the Code Review workflow calling validate-v2.yaml, formats with oxfmt, includes the Trivy configuration, and authenticates to GitHub Packages. dx add environment registers tenant-qualified environments in nx.json, and dx doctor validates the Nx Terraform plugin instead of the legacy pre-commit configuration.
