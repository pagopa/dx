Retire the optional version-plan warning workflow

## Migration guide

The retired optional validation workflow commented on pull requests when version
plans were missing or incomplete. Remove its call from your repository's
validation workflow and use the supported `validate-v2.yaml` workflow for code
review and CI checks. It does not replace the version-plan warning. Run
`pnpm nx release plan` and verify `.nx/version-plans/` before opening a pull
request.
