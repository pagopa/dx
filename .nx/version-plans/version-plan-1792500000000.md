Authenticate the reusable workflows to GitHub Packages before installing dependencies. `release-v2`, `validate-v1`, `release-terraform-v1`, `deploy-v1`, `release-azure-staticapp-v1` and `release-azure-staticassets-v1` now run `setup-npm-registry`, so consumers that reference DX packages through pnpm's `gh:` alias no longer fail with `ERR_PNPM_FETCH_401`.

Because a reusable workflow can only downgrade the permissions granted by its caller, the calling jobs must declare `packages: read` (`packages: write` for releases). The action README and the consumer docs now describe the requirement and explain that Yarn 2+ ignores the exported npmrc.
