Add optional `terraform_state_container_access` for container-scoped state
permissions. Keep `null` for unchanged legacy behavior; opt in to Contributor on
the own container and grant Reader only to explicitly selected upstream
recipients. Use each upstream container name as its map key for the configured
storage account, or its exact ARM container ID when it uses legacy coordinates
or another account.

Before enabling, publish the bootstrap module, deploy the matching core roles
to the target environment, and prepare any Reader grant required by the first
plan; import pre-existing assignments when adopting them into module
management. Existing state backends are not migrated.
