---
setup-npm-registry: patch
---

Store the GitHub Packages credential in a dedicated npmrc under `runner.temp` instead of the user-level `$HOME/.npmrc`, and expose the file through the new `npmrc-path` output.

The user-level npmrc is loaded by every npm and pnpm invocation of the job, so the `${NODE_AUTH_TOKEN}` placeholder made each later step that does not export the variable print `Failed to replace env in config: ${NODE_AUTH_TOKEN}`. Consumers now point `NPM_CONFIG_USERCONFIG` at the output on the steps that install or publish packages, which keeps the placeholder out of unrelated steps. `validate-v2.yaml` and `nx-release` are updated accordingly:
```yaml
- name: Setup npm registry
  id: setup-npm-registry
  uses: pagopa/dx/actions/setup-npm-registry@main

- name: Install dependencies
  env:
    NODE_AUTH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
    NPM_CONFIG_USERCONFIG: ${{ steps.setup-npm-registry.outputs.npmrc-path }}
  run: pnpm --filter . ci
```
