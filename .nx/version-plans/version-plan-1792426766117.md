setup-npm-registry: patch
---

Replace the `${NODE_AUTH_TOKEN}` placeholder with the token itself, expanded once when the action writes the npmrc. A placeholder is re-evaluated by every npm and pnpm invocation that loads the file, so each step that could not see the variable printed `Failed to replace env in config: ${NODE_AUTH_TOKEN}`.

The action now receives the credential through a required `token` input, writes it to a `0600` npmrc under `runner.temp` instead of `$HOME/.npmrc`, and exports `NPM_CONFIG_USERCONFIG` for the rest of the job. Consumers configure a single variable:
```yaml
- name: Setup npm registry
  uses: pagopa/dx/actions/setup-npm-registry@main
  with:
    token: ${{ secrets.GITHUB_TOKEN }}

- name: Install dependencies
  run: pnpm --filter . ci
```
