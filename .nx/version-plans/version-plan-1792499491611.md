Install Python 3.12.15 for certificate renewal, with Linux x64 builds available for both Ubuntu 24.04 and 26.04.

Add a credential-free Ubuntu 24.04/26.04 diagnostic for Node bootstrap, provider
unit tests, Terraform CLI, Docker/archive operations, TLS imports, CSR/PFX checks,
and synthetic plan cross-decryption. These checks do not certify real certificate
renewal or deployments. Existing workflow runners, caches, and cloud resources
remain unchanged.
