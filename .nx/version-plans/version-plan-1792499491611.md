Install Python 3.12.15 for certificate renewal, with Linux x64 builds available for both Ubuntu 24.04 and 26.04.

Pin hosted workflow runners to Ubuntu 26.04, except for documented temporary
Ubuntu 24.04 holds covering full TLS renewal, legacy SDK/Terraform consumers,
Next.js compatibility checks, and Azure native artifact builds. Existing
self-hosted selection and workflow inputs remain unchanged. Isolate hosted
Nx/Turbo build caches between operating systems and toolchains.

See `.github/ubuntu-runners.md` for exception exit criteria and validation
limits. Consumers pinned to older DX commits retain their runner selection;
consumers using `@main` receive the migration when merged. If a consumer regresses,
pin its workflow call to the last known-good DX commit while investigating.
