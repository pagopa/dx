When initializing an Azure subscription, grant the bootstrap CI identity
`Container Apps Jobs Operator` at subscription scope, in addition to `Reader`
and `Storage Blob Data Contributor`. This built-in role also allows reading
Container Apps job secrets.

Existing initialized subscriptions are not automatically updated. An
administrator can assign the missing role to an existing bootstrap CI identity:

```bash
az role assignment create \
  --assignee-object-id <bootstrap-ci-principal-id> \
  --assignee-principal-type ServicePrincipal \
  --role b9a307c4-5aa3-4b52-ba60-2b17c136cd7b \
  --scope /subscriptions/<subscription-id>
```
