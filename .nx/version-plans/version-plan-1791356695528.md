Add a repeatable `--skill` option to `harbor-bench compare` to inject auxiliary skills (e.g. eval dependencies) into both runs, with the tested skill always winning on name collisions, and document installing the CLI from the public repo with `uv tool install`. The agent and judge default models move to `gpt-6-luna`. The JSON comparison report now names the two gate outcomes explicitly: `base_gate_passed`/`head_gate_passed` replace `base_passed`/`head_passed` in the `comparison` and `summary` objects, per-task sides keep `completed` and `eval_passed`, and the ambiguous `passed` alias is removed.
