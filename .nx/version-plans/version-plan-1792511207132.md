aws_github_environment_bootstrap: minor
---

Always create a dedicated token-only OIDC role and the repository-level ECR_PUBLIC_ROLE_ARN secret in the AWS bootstrap. Ignore subsequent secret value changes to avoid ARN churn between environment states. Initial creation can overwrite an existing secret, and destroying an instance can delete the shared secret; coordinate creation, role rotation and retirement across states. ECR Public authentication still requires organization policies to permit us-east-1. Validation uses only the official AWS authentication actions, with optional non-blocking login; it does not clear pre-existing Docker credentials, which must be managed on self-hosted runners.

Grant sts:GetServiceBearerToken without a service-name condition, matching the documented AWS ECR Public policy and avoiding a condition-dependent implicit Deny. The role still grants only the two token actions; bearer-token permission is no longer limited to ECR Public, and no repository write or additional service API permissions are added.
