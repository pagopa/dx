aws_github_environment_bootstrap: minor
---

Always create a dedicated token-only OIDC role and the repository-level ECR_PUBLIC_ROLE_ARN secret in the AWS bootstrap. Ignore subsequent secret value changes to avoid ARN churn between environment states. Initial creation can overwrite an existing secret, and destroying an instance can delete the shared secret; coordinate creation, role rotation and retirement across states. ECR Public authentication still requires organization policies to permit us-east-1.
