Restrict AWS deployment role federation to each matching GitHub environment while preserving both supported repository subject formats. Keep repository-wide trust only on the dedicated token-only ECR Public login role.

## Migration guide

Upgrade `pagopa-dx/aws-github-environment-bootstrap/aws` from 2.x to `~> 3.0`.
Jobs assuming infra/app CI/CD roles must declare their matching
`infra-<env>-ci`, `infra-<env>-cd`, `app-<env>-ci` or `app-<env>-cd` GitHub
environment. Include `environment.prefix` in `<env>` when
`github_environment_prefix_enabled` is true. Jobs without an environment and
custom environments no longer match deployment-role trust.

Review environment protection rules before applying the bootstrapper upgrade with an authorized IAM administration principal. Existing role names, ARNs, permissions, outputs and secrets are preserved; no role replacement or state move is required. ECR Public repository trust and its shared secret remain unchanged. Publishing this module does not update live policies: each consumer must upgrade and apply its bootstrapper configuration.
