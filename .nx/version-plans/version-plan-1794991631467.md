Recognise the test blocks created with `test.extend()`: oxlint does not follow the fixtures a test object is extended from, so every `expect` inside an extended block was reported as standalone. Both flavours now pass `additionalTestBlockFunctions: ["it", "test"]` to `no-standalone-expect`, which clears the false positives and still flags an `expect` sitting outside a test block. The README gains the exemptions and the coverage holes the migration left open.
