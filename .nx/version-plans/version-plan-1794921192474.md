Bootstrap the scaffold on pnpm 12: `dx init` pins `corepack use pnpm@12`, and the DX Nx plugins install with the `gh:` prefix in the version slot (`@pagopa/nx-docker@gh:latest`), since pnpm 12 rejects the prefix-first form. The generated `pnpm-workspace.yaml` needs no change.
