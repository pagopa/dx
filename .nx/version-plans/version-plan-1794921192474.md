Bootstrap the monorepo scaffold on pnpm 12: `dx init` now pins the workspace to pnpm 12 through `corepack use pnpm@12`, so generated repositories start on the current major instead of pnpm 11. pnpm 12 changed the syntax of the `gh:` registry prefix, which the scaffold uses to install the DX Nx plugins from GitHub Packages: the alias now belongs to the version slot, so the CLI installs `@pagopa/nx-terraform@gh:latest` and `@pagopa/nx-docker@gh:latest` instead of the prefix-first `gh:@pagopa/nx-terraform`, which pnpm 12 rejects with `ERR_PNPM_INVALID_DEPENDENCY_NAME`. The generated `pnpm-workspace.yaml` needs no change: `allowBuilds`, `linkWorkspacePackages`, `cleanupUnusedCatalogs` and `packageImportMethod: clone-or-copy` are all still valid settings. The plugin `README.md` now documents the same `gh:` syntax for manual installs.
