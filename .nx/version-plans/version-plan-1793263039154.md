Use the GitHub App Client ID as the runner registration JWT issuer.

## Migration guide

Before deploying this image, configure GITHUB_APP_CLIENT_ID for every GitHub App runner; GITHUB_APP_ID alone no longer authenticates this image. Upgrade the runner Terraform module and provision github-runner-app-client-id in the common Key Vault first. The Azure GitHub environment bootstrap module pins runner module 3.x and hardcodes the DX image's latest tag, so release and apply a bootstrap upgrade using the new runner module major before publishing this image as latest. Other deployments using latest should pin the previous image until migrated. PAT and registration-token authentication are unchanged.
