Use the GitHub App Client ID as the runner registration JWT issuer.

## Migration guide

Before deploying this image, configure GITHUB_APP_CLIENT_ID for every GitHub App runner; GITHUB_APP_ID alone no longer authenticates this image. Upgrade the runner Terraform module and provision github-runner-app-client-id in the common Key Vault first. The latest image tag may update existing deployments automatically; pin the previous image during migration if needed. PAT and registration-token authentication are unchanged.
