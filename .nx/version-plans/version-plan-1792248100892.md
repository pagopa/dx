setup-npm-registry: patch
---

New `setup-npm-registry` GitHub Action that authenticates npm and pnpm to the GitHub Packages registry that hosts DX packages. The token is passed as a `token` input, written expanded to a private npmrc under `runner.temp`, and `NPM_CONFIG_USERCONFIG` is exported for the rest of the job, so consumers configure a single variable and no step has to resolve a `${VAR}` placeholder. `validate-v2.yaml` now uses the action instead of repeating the npmrc bootstrap in every job.
