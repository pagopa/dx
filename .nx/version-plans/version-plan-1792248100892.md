setup-npm-registry: patch
---

New `setup-npm-registry` GitHub Action that authenticates npm and pnpm to the GitHub Packages registry that hosts DX packages. It stores the credential as a `${NODE_AUTH_TOKEN}` placeholder in the user-level npmrc, so the token is never written to disk and the steps that install dependencies only have to expose it in their own environment. `validate-v2.yaml` now uses the action instead of repeating the npmrc bootstrap in every job.
