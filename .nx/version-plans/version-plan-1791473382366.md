Prepare for the later AzureRM v5 migration while remaining v4-only. Preserve VPN BGP, disabled Cosmos local authentication, storage CMK automatic rotation, and storage subresource identity using supported property names; remove a redundant empty VPN subnet endpoint list. Minimum AzureRM versions change from 4.0 to 4.62 for VPN, 4.78 for Cosmos, and 4.81 for Storage. Storage requires 4.81 because versions 4.77-4.80 force table replacement when changing from the account name to its ID; 4.81 supports the same-account in-place transition. Core retains its existing provider range. Run terraform init -upgrade for older provider locks. Public module inputs and outputs are unchanged. This release adds no AzAPI dependency or manual state migration and does not add AzureRM v5 support. Full v5 migration and cloud integration/e2e validation are deferred to CES-2367.
