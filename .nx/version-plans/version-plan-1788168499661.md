Configure MCP server releases to publish the versioned Docker image instead of
the npm package. Nx Release now pushes the full version, minor alias, and
`latest` tags to the configured container repository.

Document Docker-only package releases and the monorepo Docker build layout in
the Docker plugin README and the website guide. The `@pagopa/nx-dx-docker-plugin`
and `docs` patch entries cover those published documentation changes; the plugin
runtime behavior is unchanged.
