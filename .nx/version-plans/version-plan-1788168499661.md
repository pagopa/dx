Configure MCP server releases to publish the versioned Docker image instead of
the npm package. The project remains private to npm but is tagged `public` for
the release workflow, which selects projects by publishability before Nx
publishing runs. Nx Release now pushes the full version, minor alias, and
`latest` tags to the configured container repository.

Document package projects released only as Docker images and the monorepo Docker
build layout. The plugin README keeps a short package-specific quick start and
links to the website guide, which is the canonical detailed reference. The
`@pagopa/nx-dx-docker-plugin` entry covers the README, while the `docs` entry
covers the website guide; both entries are needed because they are published by
different Nx projects. The plugin runtime behavior is unchanged.
