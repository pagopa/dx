Require validated code owners for organization initialization and align CODEOWNERS with deployment reviewer teams.

## Migration guide

One or more repeatable `--code-owner` flag is now required, for example: `dx init --name my-project --owner pagopa --code-owner @pagopa/product-team --code-owner @pagopa/design-team`.
Personal namespaces automatically include `@owner` as codeowner, and may add individual code owners. Individual code owners are not set as reviewers of GitHub workflows as only teams are accepted
