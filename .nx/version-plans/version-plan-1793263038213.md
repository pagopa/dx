Require the GitHub App Client ID secret in runner jobs.

## Migration guide

Before upgrading, add github-runner-app-client-id to the Key Vault with the Client ID of the same GitHub App. Keep github-runner-app-id for KEDA. Upgrade and apply the runner module before updating the DX runner image; the Azure GitHub environment bootstrap module currently pins runner module 3.x and must first be upgraded to a release using the new major. The separately maintained default runner image still uses App ID authentication.
