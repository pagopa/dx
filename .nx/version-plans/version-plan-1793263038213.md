Require the GitHub App Client ID secret in runner jobs.

## Migration guide

Before upgrading, add github-runner-app-client-id to the Key Vault with the Client ID of the same GitHub App. Keep github-runner-app-id for KEDA. Upgrade and apply the runner module before updating the DX runner image. The Azure GitHub environment bootstrap module pins runner module 3.x and hardcodes the DX image's latest tag: release and apply a bootstrap upgrade using this new major before publishing the Client ID-based DX image as latest. The separately maintained default runner image still uses App ID authentication.
