Require callers to provide an `aws.us-east-1` provider configuration for the CloudFront-scope WAF ACL while keeping other resources in the configured deployment region.

Expose the WAF web ACL name and ARN through the CloudFront output when enabled.

## Migration guide

Configure an AWS provider alias for `us-east-1` and pass it to the module alongside the default provider:

```hcl
provider "aws" {
  region = "eu-south-1"
}

provider "aws" {
  alias  = "us-east-1"
  region = "us-east-1"
}

module "open_next" {
  source = "pagopa-dx/aws-open-next/aws"

  providers = {
    aws           = aws
    aws.us-east-1 = aws.us-east-1
  }
}
```

Add this provider mapping to every module call, including configurations where WAF is disabled.
