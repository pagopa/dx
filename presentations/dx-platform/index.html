Perché è una piattaforma e non una collezione di tool

Un deploy attraversa tutti i layer

Esempio: la release di citizen-api su Container App.

L01 · BOOTSTRAP IAM del deploy GitHub Environment *-cd · federated identity: nessun secret da copiare.
L00 · TOOLCHAIN Build riproducibile pnpm nx build · la stessa toolchain di dev, con cache e affected.
L03 · MODULI Configurazione azure_container_app: immagine, variabili, segreti, scale.
L04 · PIPELINES Orchestrazione release-azure-containerapp-v1: build → push → deploy, zero YAML duplicato.
L02 · HUB & SPOKE Destinazione Key Vault, API gateway e rete privata già presenti nell'ambiente.
L06 · OSSERVABILITÀ Feedback Trace su App Insights · dashboard rigenerate dall'OpenAPI.

Rimuovi un layer e il deploy torna un lavoro da esperti.
