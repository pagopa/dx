# Renovate Preset

The shared PagoPA DX Renovate preset lets repositories opt into DX-managed
dependency update rules without changing centrally managed security
configuration.

The preset is maintained in
[`renovate-presets/default.json`](https://github.com/pagopa/dx/blob/main/renovate-presets/default.json).

## Enable the Preset

Renovate must already be enabled for your repository. Add the following entry to
the `extends` array in your existing Renovate configuration:

```json
"github>pagopa/dx//renovate-presets/default"
```

For example, a root-level `renovate.json` using the recommended configuration
becomes:

```json
{
  "$schema": "https://docs.renovatebot.com/renovate-schema.json",
  "extends": [
    "config:recommended",
    "github>pagopa/dx//renovate-presets/default"
  ]
}
```

Keep any existing presets, security settings, and repository-specific rules.
Adding this preset does not install Renovate or enable automatic merging.
Repositories generated by the DX CLI already include this reference.

## Included Rules

The preset currently enables and groups **major updates to Terraform Registry
modules in the `pagopa-dx/` namespace** under the group name
`PagoPA DX Terraform modules versions`.

The rule matches the `terraform` manager, the `terraform-module` datasource, and
package names starting with `pagopa-dx/`. It does not configure Terraform
providers, modules from other namespaces, GitHub Actions, or Docker images.
Minor and patch updates continue to follow the repository's other Renovate
rules.

Major module upgrades can require infrastructure changes. Review the module's
release notes and migration instructions, and inspect the Terraform plan before
merging. This preset does not generate version plans or run post-upgrade
commands.

## Updates and Local Overrides

The reference follows the default branch of `pagopa/dx`, so consumers receive
future preset changes without editing their `extends` entry. Additional
DX-managed rules may be added to the preset over time.

Repository-level `packageRules` are applied after inherited preset rules.
Review existing rules for overlapping matches: a local rule can override
settings such as `enabled` or `groupName`.

See the [Renovate preset documentation](https://docs.renovatebot.com/config-presets/)
for details on preset resolution and referencing a specific Git tag.
