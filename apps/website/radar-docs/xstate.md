[XState](https://stately.ai/docs/xstate) is a state management and orchestration
library built on state machines, statecharts, and
the actor model. By explicitly defining states, events, transitions, and side
effects, it decouples application logic from UI components.

## Use cases

- Model complex multi-step user journeys.
- Coordinate complex asynchronous operations.
