[Reactotron](https://github.com/infinitered/reactotron) is a debugging tool for
React Native apps which provides a GUI to inspect the app's state and behavior.

Reactotron provides network request monitoring, log inspection, Redux state and
action tracking, and AsyncStorage inspection. It also supports custom plugins
for extending its capabilities.

## Use cases

- Inspect the network requests made by the app and their responses.
- Inspect the view hierarchy of the app.
- Inspect the state of the Redux store and the dispatched actions.
- Inspect and filter logs produced by the app.
- Inspect the asynchronous storage of the app to debug persisted state.
