[Proxyman](https://proxyman.io/) is a native HTTP/HTTPS proxy tool designed for
network logging, SSL proxying, and traffic manipulation across iOS, Android, and
desktop platforms.

## Use cases

- Inspect, decrypt, and debug live HTTP/HTTPS traffic from mobile devices,
  simulators, and desktop apps.
- Mock API responses locally without changing backend endpoints.
- Intercept and modify request headers, body payloads, or status codes on the
  fly using breakpoints and custom scripts.
- Simulate slow network conditions, latency, and edge cases.
