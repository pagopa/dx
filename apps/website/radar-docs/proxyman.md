[Proxyman](https://proxyman.io/) is an HTTP/HTTPS proxy tool enabling developers
to capture, inspect, and mock network traffic between clients and backend
services.

Proxyman simplifies API debugging across iOS, Android, and web platforms with
network logging, SSL proxying, and traffic manipulation.

## Use cases

- Inspect and debug HTTP/HTTPS network traffic from mobile devices and
  simulators in real time.
- Decrypt SSL traffic using automatically configured local root certificates.
- Mock API responses locally.
- Intercept and modify request headers, body payload, or status codes on the fly
  using breakpoints and scripts.
- Simulate slow network connections and edge cases.
