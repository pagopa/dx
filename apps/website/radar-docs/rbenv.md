[rbenv](https://github.com/rbenv/rbenv) is a tool that allows you to install and
switch between multiple Ruby versions seamlessly.

A `.ruby-version` file can be included in the project to specify the Ruby
version which is automatically used by rbenv.

## Use cases

- Use the right version of Ruby across projects
